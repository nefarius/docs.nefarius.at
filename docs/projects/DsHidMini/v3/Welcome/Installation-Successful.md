# DsHidMini Installed Successfully

Congratulations—DsHidMini is now installed.

## Next steps

The default **XInput** mode usually works without changing any settings. Connect an official Sony DualShock 3 or SIXAXIS controller by USB and test it with the [installation guide](../How-to-Install.md#testing-your-controller-in-windows).

For Bluetooth, install [BthPS3](../../../BthPS3/How-to-Install.md) and connect the controller by USB once to pair it. Do not pair it through Windows Bluetooth discovery.

To verify or configure the controller, download [ControlApp](https://buildbot.nefarius.at/builds/DsHidMini/latest/bin/ControlApp.exe). It requires the [.NET Desktop Runtime 10 (x64)](https://dotnet.microsoft.com/en-us/download/dotnet/10.0). You do not need to keep it open for the driver to work. For other modes, see [HID Device Modes explained](../HID-Device-Modes-Explained.md).

You can [support the authors](../../../../Donations.md) by making a donation.
